## 一、项目概述

这是一个 **NestJS 框架官方仓库**，采用 **Lerna** 进行 monorepo 多包管理，使用 TypeScript 开发。项目定位是一个高效、可扩展的 Node.js 服务端应用框架，融合了 OOP、FP 和 FRP 理念。

### 核心特性

- **模块化架构**：基于模块的系统，每个功能封装为独立的 NestModule
- **依赖注入**：通过装饰器 (@Injectable) 和 IoC 容器实现
- **适配器模式**：支持多种 HTTP 框架和通信协议
- **装饰器驱动**：大量使用 TypeScript 装饰器进行元数据声明

### 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Node.js | >= 20 | 运行时环境 |
| TypeScript | 5.9.3 | 开发语言 |
| RxJS | 7.8.2 | 响应式编程库 |
| reflect-metadata | 0.2.2 | 装饰器元数据 |
| Express | 5.2.1 | 默认 HTTP 适配器 |
| Fastify | 5.8.5 | 可选 HTTP 适配器 |
| Socket.IO | 4.8.3 | WebSocket 通信 |

## 二、packages/ 目录结构详解

### 2.1 @nestjs/common (核心公共模块)

**路径：** `packages/common`
**文件数：** 616 个文件 (423 *.ts)

**职责：** 提供框架的核心公共 API、装饰器、接口定义和工具类，是所有其他包的基础依赖。

**主要导出模块：**

| 模块 | 说明 |
|------|------|
| `decorators/` | 核心装饰器 (@Module, @Controller, @Injectable 等) |
| `decorators/http/` | HTTP 相关装饰器 (@Get, @Post, @Body 等) |
| `enums/` | 枚举定义 |
| `exceptions/` | 异常类 (HttpException 等) |
| `interfaces/` | 核心接口 (ICanActivate, PipeTransform 等) |
| `pipes/` | 管道实现 |
| `services/` | 核心服务 |
| `serializer/` | 序列化相关 |
| `file-stream/` | 文件流处理 |
| `module-utils/` | 模块工具 |

**核心接口：**
- `ICanActivate` - 守卫接口
- `PipeTransform<T, R>` - 管道接口
- `NestInterceptor` - 拦截器接口
- `ExceptionFilter` - 异常过滤器接口
- `MiddlewareConsumer` - 中间件消费者
- `DynamicModule` - 动态模块

## 六、项目整体架构特点

### 6.1 核心设计模式

1. **依赖注入 (DI)**
   - 通过装饰器 (@Injectable) 声明
   - IoC 容器自动解析依赖
   - 支持构造函数注入和属性注入

2. **模块化架构**
   - 每个功能封装为独立的 NestModule
   - 模块可以导入其他模块
   - 支持全局模块

3. **适配器模式**
   - HTTP 框架适配：Express / Fastify
   - WebSocket 适配：Socket.IO / 原生 ws
   - 微服务传输：TCP / Redis / Kafka / gRPC 等

4. **装饰器驱动**
   - 大量使用 TypeScript 装饰器
   - 元数据存储在 Reflect.metadata
   - 运行时通过 MetadataScanner 扫描

5. **中间件管道**
   - 请求经过多层处理
   - 可自定义拦截器、守卫、管道
   - 支持异常过滤器

### 6.2 请求处理流程

```
请求 → 中间件 → 守卫 → 拦截器(前) → 管道 → Controller → Service → 管道 → 拦截器(后) → 响应
              ↓                                                        ↓
         异常过滤器 ←─────────────────────────────────────────────────┘
```

### 6.3 生命周期钩子

| 钩子 | 说明 |
|------|------|
| `OnModuleInit` | 模块初始化时调用 |
| `OnModuleDestroy` | 模块销毁时调用 |
| `OnApplicationBootstrap` | 应用启动完成 |
| `OnApplicationShutdown` | 应用关闭时调用 |
| `BeforeApplicationShutdown` | 关闭前调用 |

### 6.4 构建与发布

**构建工具：**
- **TypeScript**：核心开发语言
- **Lerna**：monorepo 包管理
- **Gulp**：构建任务自动化
- **ESLint/Prettier**：代码规范

**npm 脚本：**
```bash
npm run build        # 构建所有包
npm run test         # 运行单元测试
npm run test:integration  # 运行集成测试
npm run lint         # 代码检查
npm run format       # 代码格式化
```
